How the map stays current

The website structure is regenerated by the existing Hub publishing process. Open the latest page after a release. Independent research links are checked when the map opens online and when you choose Refresh report links.

Know the limits

Page discovery comes from this repository snapshot. Key dependencies were reviewed in code and documentation. Optional references are inferred from filenames. Private automation schedules need a separate review after changes; source tasks are not monitored, and the map cannot prove a scheduled reply was produced.

Keyboard: / search · + / − zoom · Home fit · arrow keys pan · Escape clear trace. The List view provides a searchable alternative to the spatial canvas.
