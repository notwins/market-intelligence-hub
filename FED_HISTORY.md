The V4 FX and Treasury history checks Federal Reserve monthly observations via FRED every Saturday at 06:17 UTC. GitHub scheduled jobs can be delayed. A manual workflow dispatch also refreshes history. The first publication initializes the feed. This updates monthly history, not daily market quotes or individual-bond yields.

The original `site/data/history-v3.json` is unchanged and remains selectable, including its Singapore SGS observations. Its workbook uses monthly Board H.10 FX and H.15 constant-maturity series. All 8,234 overlapping Fed/cross observations matched the first validated FRED retrieval. The newer workbook named “part 2” was locked by Excel and has not been used. SGS is not supplied by this Fed connection.

`scripts/update_fed_history.py` maps ten direct FX pairs to EXUSAL, EXUSEU, EXUSNZ, EXUSUK, EXCHUS, EXHKUS, EXJPUS, EXMAUS, EXSIUS and EXSZUS. Treasury 1M/3M/6M and 1Y/2Y/3Y/5Y/7Y/10Y/20Y/30Y map to GS1M, GS3M, GS6M and GS1, GS2, GS3, GS5, GS7, GS10, GS20, GS30. CHF/SGD is the ratio of monthly USD/SGD and USD/CHF averages on matching periods, not an average of daily cross rates. Units, original provider links, aggregation, observation months and retrieval time accompany every series. No API credential is embedded or needed for the public CSV download.

`site/data/history-fed.json` uses schemaVersion 1 and contractVersion `market-history-series/1.0.0`. Each series has sorted `[observation_month, value]` points and explicit missing_periods. Dates denote months using their first day; current incomplete months are excluded. Missing values are never zero or forward-filled. USREC is separately attributed to the St. Louis Fed interpretation of NBER chronology, with the month following a peak through the trough shaded. Its end boundary is exclusive. The indicator is checked for missing months before shading is accepted.

Every changed provider dataset is retained under `history-fed-archive/<content-hash>.json`. Same-period changes are recorded as old/new revisions. Provider failure, stale observations, malformed data or regressed coverage preserve the last successful dataset, publish a visible failure status, and fail the workflow after retaining the usable site. The public search catalogue is rebuilt after data refresh, preserving existing search and watchlist behavior.

The supplied Fed series are tagged Public Domain: Citation Requested. USREC is Copyrighted: Citation Required. The UI includes source attribution and links. FRED terms: https://fred.stlouisfed.org/legal/. Event groups retain individual official source links and identify announcement/effective dates as context, not causation. The NBER chronology cross-check is https://www.nber.org/research/data/us-business-cycle-expansions-and-contractions.

Portfolio Simulation integration is a separate task. This publication provides the versioned series dataset but does not itself change any Portfolio chart, holding, recorded price, FX assumption, loan or financial calculation. No private workbook or portfolio file is published.
