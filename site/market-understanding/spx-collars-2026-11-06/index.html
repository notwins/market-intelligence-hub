SPX put-and-call collars

A put can protect an expiry value. Selling a call helps pay for it by giving up upside. The history shows the size of that trade-off; market quotes determine whether a particular collar can be entered at zero net option premium.

Four takeaways

  1. The floor helped in 17 years; the cap constrained 38. Ten years stayed between 0% and 9%, inclusive. These are sample frequencies, not future odds.
  2. Removing negative annual outcomes did not maximise compounded wealth. A starting 100 became 11,780.24 for the price index and 3,871.85 under the hypothetical annually reset rule, before dividends and costs.
  3. A fixed 0% floor and 9% cap are not automatically zero-premium. The report has no historical option quotes. Its pricing example is a model illustration, explicitly separate from a trade.
  4. Starting month matters, and protection has a maturity date. The heatmap shows 97 overlapping one-year windows. It does not measure daily collar values or establish a guarantee on early exit.

01 / How the collar works

Three positions create one expiry payoff

The protection comes from the put; the funding contribution comes from the call sold. The investor also needs underlying equity exposure. For the clean illustration, use matching notionals, the same one-year expiry, a put strike equal to the starting reference level, and a call strike 9% above it.

1

Hold the underlying exposure

Participate in changes in the reference price. In practice this means an equity basket or tracking vehicle; the index itself is a calculation.

2

Buy a protective put

At expiry, the put pays when the reference settles below its strike. Buying this protection costs a premium.

3

Sell a call

Receive a premium and owe the payoff above the call strike. This gives up part of the underlying’s upside.

Mechanics: OIC protective collar; contract details are checked separately below. [10]

06 / Can the call pay for the put?

Zero net premium is a market-pricing condition

Choosing a 0% floor and a 9% cap does not make the premiums equal. At a specified timestamp, a conservative separate-leg screen is put ask minus call bid. A package quote may differ; available strikes, size and liquidity still have to support the actual execution.

Net option debit d = Pask(Kp, T) − Cbid(Kc, T).
Zero net option premium requires d = 0; it does not eliminate costs or surrendered upside.

Capital accounting

The premium changes the return denominator

Paying the model debit requires 102.06639908 of initial capital. If the expiry price component is 100, the return on that expenditure is approximately −2.024564%. At an expiry value of 109, it is approximately +6.793226%.

Return on capital = VT ÷ (100 + d) − 1

This example excludes dividends and all other costs. Borrowing the debit instead creates a separate financing cash flow. A 0% reference-price floor is not a 0% return on a larger initial expenditure.

Independent calculation using the model debit above; indicative illustration only. [11]
Feasibility condition

Solve for a feasible cap or floor

Fix the put strike and solve for the call strike—or fix the cap and solve for the put strike. A real zero-premium collar is the result of that pricing exercise. It is not the result of clipping a chart.

Strike ordering matters. Retain Kp ≤ Kc. In the stated continuous-yield model, an ATM put cannot be financed by a call at or above spot when the interest rate is below the dividend yield; at equal rates, the equal-premium cap is 0%.

This is a model feasibility condition from put–call parity, not a universal quote rule. Market skew and execution frictions require actual prices.

07 / What survives outside the payoff diagram?

Execution and cash flows determine the account return

A clean expiry diagram is a starting point for implementation. Dividend income, actual holdings, option settlement, costs, funding and the investor’s base currency all affect the account result.

Timing and costs

A maturity floor is not an early-exit guarantee

Before expiry, both options still have market values. Changes in implied volatility, skew, remaining time, rates and dividends affect those values. Closing the combined position realises available prices, not the expiry diagram.

Liquidity and execution can matter most when protection is needed. Spreads and the ability to close both legs together can change the result; closing one leg leaves a different exposure. Exchange and broker fees, funding, taxes and operational errors also belong in the implementation review.

OCC liquidity, combination and margin risks; OIC pricing inputs. No daily historical collar marks were obtained. [12] [14]
Currency exposure

A USD floor is not an SGD floor

Currency conversion is a separate source of return. For an unhedged SGD-based account, let FX be SGD per USD:

RSGD = (1 + RUSD) × (FXend ÷ FXstart) − 1

Illustrative example: a 0% USD result with a 5% fall in SGD per USD gives −5% in SGD. This is arithmetic, not an FX forecast. Hedging currency introduces its own pricing and cash flows.

Nominal protection also does not preserve purchasing power against inflation. No current FX price is used in this report.

The legal wrapper changes the risk. A listed-options position, an OTC contract and an issuer note are different arrangements. If exposure is packaged into an OTC or issuer product, counterparty or issuer credit, collateral, liquidity and early-termination provisions must come from its documentation. No actual product terms are inferred here.
08 / Evidence, uncertainty and next steps

Use the history to explain the trade-off; use quotes to price it

The supported conclusion is specific: in this 65-year price sample, the annual 0%–9% transformation removed negative annual returns and reduced return dispersion, while sacrificing enough upside to finish with materially lower wealth. Whether a particular collar is attractive or zero-premium today is a separate, unanswered question.

Conditional outlook

What could change the assessment?

  • Different observed option quotes: put/call skew, rates and expected dividends change which floor and cap can finance each other.
  • A different objective: a willingness to accept some downside, pay a debit or surrender more upside changes the structure.
  • A different horizon: tenor, expiry conventions and reset dates alter both the price and the exposure.
  • A different implementation: dividends, fees, tax, tracking and FX can materially change account returns.

These are qualitative scenarios. No target, probability, analyst call or future price path has been invented.

Limitations

What remains unresolved?

  • Historical executable quotes: the specific annual 0% / 9% zero-premium claim has not been tested.
  • Daily strategy marks: daily volatility, drawdown and early-exit values are not available from clipped annual returns.
  • Longer heatmap validation: this report verifies only the 109 monthly endpoints shown; the wider stored site history is not promoted to a verified dataset.
  • Source use: historical observations are attributed to their published sources and included for reproducibility of this educational analysis. This report does not grant a licence to resell source data or imply endorsement by index or data providers.

Practical review checklist

  1. Freeze the data definition. Record source, observation dates, price versus total return, precision and excluded periods. Keep 2011’s negative sign and the 17 / 10 / 38 denominator intact.
  2. Specify the trade completely. Identify the actual underlying holdings, option symbol, put and call strikes, expiry, settlement convention, quantity and reset timestamp.
  3. Obtain simultaneous executable prices. Record bid/ask, size and package price. Solve the cap or floor from those quotes, subject to available strikes.
  4. Build the cash-flow ledger. Include dividends, premium debits/credits, financing, fees, spreads, taxes, collateral and FX. Use total capital spent as the return denominator.
  5. Stress the exit and settlement. Examine early liquidation, basis differences, insufficient cash and one-leg execution. Check credit terms for any OTC or issuer wrapper.
  6. Review the presentation and intended use. Keep source dates, units, line styles and caveats beside the figures. A commercial data product or investment product requires a separate rights and compliance review.

Reproduce the main comparison

import csv, math, statistics
from decimal import Decimal as D

# Download the annual-level CSV from this report's HTML.
rows = list(csv.DictReader(open("spx_year_end_levels_1960_2025.csv")))
levels = [D(row["index_close"]) for row in rows]
r = [float(b / a - 1) for a, b in zip(levels, levels[1:])]
g = [min(max(x, 0.0), 0.09) for x in r]
assert len(r) == 65
assert (sum(x < 0 for x in r),
        sum(0 <= x <= .09 for x in r),
        sum(x > .09 for x in r)) == (17, 10, 38)

def metrics(ret):
    wealth = [100.0]
    for x in ret:
        wealth.append(wealth[-1] * (1 + x))
    peak, mdd = wealth[0], 0.0
    for x in wealth:
        peak = max(peak, x)
        mdd = min(mdd, x / peak - 1)
    return {"terminal": wealth[-1],
            "cumulative": wealth[-1] / 100 - 1,
            "CAGR": (wealth[-1] / 100) ** (1 / len(ret)) - 1,
            "annual_sample_vol": statistics.stdev(ret),
            "annual_end_drawdown": mdd}

print(metrics(r), metrics(g))
# Sum of annual changes in pp; not cumulative returns:
print("downside removed:", sum(max(-x, 0) for x in r) * 100)
print("upside surrendered:", sum(max(x-.09, 0) for x in r) * 100)
# Rolling windows: use consecutive month-end levels m[i+12]/m[i]-1.
# Require all 13 endpoints; never compound overlapping windows.

Floating-point output: last-digit differences can arise between software. Published precision does not support interpreting those last digits as economic accuracy. The reported two-decimal display results and integer category counts reproduce consistently.

Reproduce the pricing illustration

d1 = [ln(S/K) + (r − q + σ²/2)T] / (σ√T); d2 = d1 − σ√T
C = S e−qTN(d1) − K e−rTN(d2)
P = K e−rTN(−d2) − S e−qTN(−d1)

N is the standard normal cumulative distribution function. Use S = 100, T = 1, r = 0.03, q = 0.015 and σ = 0.20; evaluate the put at K = 100 and the call at K = 109. Then solve C(Kc) = P(100), retaining Kc ≥ 100. These are model assumptions, not observed market quotes.
